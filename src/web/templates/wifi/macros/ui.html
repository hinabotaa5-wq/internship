{# このファイルは「Jinjaマクロ」を集めたファイルです。 Jinjaマクロとは、Pythonの「関数」のようなものをHTMLテンプレートの中で 定義できる仕組みです。同じ見た目のHTML（ボタンやカードなど）を 何度も書くのではなく、1回マクロとして定義しておき、 使いたい場所で {{ macro名(引数) }} のように呼び出すだけで済むようにします。 このファイルにあるマクロは、components.css で定義したクラス名 （.btn, .choice-card, .stepper など）をHTMLに割り当てる役目だけを持ちます。 見た目の詳細（色・余白など）はCSS側の責任、 「どんな構造のHTMLを組み立てるか」はこのマクロ側の責任、という分担です。 他の画面のテンプレートからこのファイルを使うには、まずファイルの先頭で 以下のように import する必要があります： {% import "wifi/macros/ui.html" as ui %} そのあとで、例えば以下のようにマクロを呼び出せます： {{ ui.button("送信する", url=url_for("app.wifi.support_id")) }} #} {# button マクロ：ボタンを1つ描画する。 引数: label - ボタンに表示する文字（例："次へ"） url - ボタンをクリックしたら移動するリンク先。 指定しない場合は {% endif %} {% endmacro %} {# choice_card マクロ：診断質問などの「選択肢」を1つ描画する。 引数: label - 選択肢に表示する文字（例："はい、特定の部屋だけ遅い"） value - 選択肢を識別するためのID。日本語の表示文とは別に、 英小文字とアンダースコアのID（CLAUDE.md 規則3）を渡す。 例: "slow_specific_room" selected - true の場合、選択済みの見た目（is-selectedクラス）にする。 実際に「クリックしたら選択状態になる」という動きはJavaScript側で data-value 属性を読み取って実装する想定。このマクロはHTMLの構造だけを作る。 #} {% macro choice_card(label, value, selected=false) %} {% set css_classes = "choice-card" %} {% if selected %} {% set css_classes = css_classes ~ " is-selected" %} {% endif %} {# data-value 属性に選択肢のID（英小文字＋アンダースコア）を持たせておく。 JavaScript側は、日本語の表示文（label）を見て分岐するのではなく、 この data-value の値を見て「どの選択肢が選ばれたか」を判定する （CLAUDE.md 規則3：表示文とIDを分離する）。 #}
